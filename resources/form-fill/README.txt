วิธีกรอกแบบฟอร์มลงทะเบียนอัตโนมัติจากไฟล์นี้ (Windows)
=====================================================

ใช้ได้ทุกเว็บลงทะเบียน (Google Form หรือเว็บอื่นของอุทยาน/หน่วยงาน)
เปิดหน้าลงทะเบียนเองแล้วสั่งกรอกได้เลย สคริปต์กรอกลงหน้าที่เปิดอยู่ ไม่เปิดหน้าใหม่

ในไฟล์ ZIP มี
  data.json              ข้อมูลทั้งรอบ (ลูกทริป + ทีมงาน)
  01-ชื่อ นามสกุล\        โฟลเดอร์ของลูกทริปแต่ละคน
      data.json          ข้อมูลของคนนี้คนเดียว
      id_card.*          รูปบัตรประชาชน (คนที่ไม่ได้แนบจะไม่มีไฟล์)
      permit.pdf         แบบฟอร์มอุทยาน (เฉพาะทริปที่ผูกแบบฟอร์ม)
      เริ่มกรอกฟอร์ม.bat  ดับเบิลคลิก = กรอกเฉพาะคนนี้
      autofill.js        สคริปต์ (ตัวเดียวกับชั้นบนสุด)
      README.txt         วิธีใช้ (ไฟล์นี้)
  NN-ทีมงาน-ชื่อ\         โฟลเดอร์ของทีมงานประจำรอบ (ข้อมูลจากโปรไฟล์สตาฟ ไม่มีรูปบัตร)
  เริ่มกรอกฟอร์ม.bat      ดับเบิลคลิก = กรอกทั้งรอบ
  autofill.js            สคริปต์กรอกฟอร์ม ฉบับล่าสุด

วิธีใช้ (Windows 10/11)
  1) แตก ZIP ก่อน (คลิกขวา → Extract All) — ดับเบิลคลิกจากใน ZIP ตรง ๆ ไม่ได้
  2) ดับเบิลคลิก "เริ่มกรอกฟอร์ม.bat" ในโฟลเดอร์ที่จะกรอก
       ชั้นบนสุด         = ทั้งรอบ
       ในโฟลเดอร์ของคน   = คนนั้นคนเดียว
     ถ้า Windows ขึ้น "Windows protected your PC" กด More info → Run anyway
  3) ครั้งแรกของเครื่อง สคริปต์ติดตั้งโปรแกรมที่ต้องใช้ให้เอง (ต้องต่อเน็ต รอ 1-2 นาที)
  4) สคริปต์เปิดหน้าต่าง Chrome ของมันเองให้ (ไม่มี Chrome จะใช้ Edge แทน)
     และขึ้นรายชื่อทุกคนในหน้าต่างดำ พร้อมบอกว่าใครยังขาดข้อมูลอะไร / ใครยังไม่เซ็นแบบฟอร์ม
     — ตามขอข้อมูลก่อนเริ่มจะลงทะเบียนได้รวดเดียว
     ถ้าเว็บเปิดฟอร์มเป็นหน้าต่างเด้ง สคริปต์กรอกเฉพาะในหน้าต่างนั้น
  5) ในหน้าต่าง Chrome นั้น เปิดหน้าลงทะเบียนตามปกติ (ล็อกอิน/กดไปจนถึงหน้ากรอกข้อมูล)
     ** ต้องเป็นหน้าต่าง Chrome ที่สคริปต์เปิด — Chrome ปกติของเครื่องสคริปต์มองไม่เห็น **
     ล็อกอินครั้งแรกครั้งเดียว ครั้งต่อไปจำไว้ให้
  6) กลับมาที่หน้าต่างดำ แล้วพิมพ์
       3          กรอกคนที่ 3 ลงหน้าที่เปิดอยู่
       Enter      กรอกคนถัดไปที่ยังไม่ได้กรอก
       1-4        กรอกคนที่ 1 ถึง 4 ต่อกันในหน้าเดียว (เว็บที่มีช่องของหลายคนในหน้าเดียว)
       3!         กรอกคนที่ 3 ทับช่องที่มีข้อมูลอยู่แล้ว — ปกติสคริปต์ข้ามช่องที่กรอกไว้
                  (เว็บที่มีหลายคนในหน้าเดียว พิมพ์ 1 แล้วพิมพ์ 2 คนที่ 2 จะลงชุดช่องถัดไป ไม่ทับคนที่ 1)
       ลิงก์       วางลิงก์ https://... = เปิดลิงก์นั้นในแท็บที่เปิดอยู่
       a          เปิดแท็บละคน ทุกคน (แบบเดิม — เหมาะกับ Google Form)
       l          ดูรายชื่ออีกครั้ง (✅ = กรอกแล้ว)
       q          ออก
  7) ตรวจในหน้าเว็บ แล้วกด "ส่ง"/"บันทึก" เอง — สคริปต์ไม่กดส่งให้
     ส่งแล้วถ้าเว็บกลับมาหน้าเปล่าให้ลงทะเบียนคนต่อไป กด Enter ได้เลย

แบ่งให้คนอื่นช่วย
  ส่งโฟลเดอร์ของคนที่เขารับผิดชอบไปให้ทั้งโฟลเดอร์ (ไม่ต้องส่ง data.json ทั้งรอบ)
    ช่วยคนเดียว   ดับเบิลคลิก เริ่มกรอกฟอร์ม.bat ในโฟลเดอร์ของคนนั้น
    ช่วยหลายคน   รวมโฟลเดอร์ของคนเหล่านั้นไว้ในโฟลเดอร์ใหม่โฟลเดอร์เดียว คัดลอก
                  เริ่มกรอกฟอร์ม.bat + autofill.js ตัวไหนก็ได้ไปวางไว้ข้างนอก แล้วดับเบิลคลิก
                  ตัวนั้น — อย่าดับเบิลคลิกตัวที่อยู่ในโฟลเดอร์ของคนใดคนหนึ่ง จะกรอกแค่คนเดียว
  ส่งเป็น ZIP ทาง LINE/อีเมลก็ได้ ให้คนช่วยแตกไฟล์ก่อนรัน

ใช้ bun / exe เองแบบเดิมก็ยังได้
  "bun autofill.js" ในโฟลเดอร์ที่จะกรอก หรือ compile เป็น exe
       bun build --compile autofill.js --outfile autofill.exe
  (โปรไฟล์ Chrome ของสคริปต์อยู่ที่ C:\chrome-autofill ที่เดิม — ล็อกอินที่เคยทำไว้ยังอยู่)

ผลลัพธ์ในหน้าต่างดำ
  ✅ ครบ · 🟡 มีช่องที่ต้องดูเอง (บอกไว้ว่าช่องไหน) · ❌ กรอกไม่ได้
  คนที่ขึ้น "ยังไม่ได้เซ็นแบบฟอร์มอุทยาน" อย่าเพิ่งส่ง
  ทีมงานไม่มีรูปบัตรประชาชนในระบบ — แนบเองถ้าเว็บขอ
  วันเกิด: สคริปต์ดูรูปแบบจากช่องเอง — ช่องปฏิทิน (ตั้งผ่านปฏิทินของเว็บ), dropdown วัน/เดือน/ปี
    (ปีในรายการเป็น พ.ศ. หรือ ค.ศ. ก็เลือกถูก), ช่องพิมพ์ที่บอกรูปแบบไว้ เช่น วว/ดด/ปปปป = พ.ศ.,
    dd/mm/yyyy = ค.ศ., "(พ.ศ.)"/"(ค.ศ.)" ในหัวข้อ หรือวันที่ตัวอย่าง 31/12/2540
    ถ้าเว็บไม่บอกอะไรเลย กรอกแบบ 14/02/2537 (พ.ศ.) และขึ้นเตือนให้ตรวจ
  คำนำหน้า: ติ๊ก (วงกลม) / dropdown / พิมพ์ ได้หมด และเทียบ นางสาว = น.ส. = Miss = Ms.
    เว็บที่ไม่มีป้าย "คำนำหน้า" (dropdown นาย/นาง/นางสาว หน้าช่องชื่อ) สคริปต์หาจากตัวเลือกให้เอง

ถ้าขึ้น "ไม่พบคำถาม ..." แปลว่าหัวข้อช่องบนเว็บไม่ตรงกับคำที่ระบบใช้หา
→ กรอกช่องนั้นเอง แล้วแจ้งทีมระบบพร้อมข้อความหัวข้อจริงบนเว็บ (แก้ที่ config/form_fill.php)

ไฟล์ในโฟลเดอร์นี้มีเลขบัตรประชาชนและเบอร์โทร — ลบทิ้งเมื่อกรอกเสร็จ
และส่งให้คนช่วยเฉพาะโฟลเดอร์ของคนที่เขาลงทะเบียน
